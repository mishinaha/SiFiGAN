# 2026-07-28 調査報告: 「極端な F0 でのノイズ化」の原因分析 — WORLD d4c の非周期性誤判定が主因

`doc/260417-1-train.md` §5 で「今回は対応しない」とした既知の制約:

> - **非常に高いF0**: ノイズ化する区間がある
> - **非常に低いF0**: F0 factor の変更が反映されない (原音の高さのまま出る) 区間がある
> - 正確な発生条件は不明。「F0がある範囲の外」という単純な閾値ではないらしい。
>   作者の事前学習モデルでも同様に再現する。

について、「F0 の極端さそのものではなく、WORLD 分析出力に異常な値 (特に NaN) が
混入しているのが原因ではないか」という仮説を検証した。

**結論の要約**:

1. **NaN / Inf は一切存在しない**。全特徴量 (f0/cf0/sp/ap/mcep/mcap/bap、正規化後含む)、
   全検体で NaN=0, Inf=0。「NaN 混入」仮説は明確に棄却。
2. しかし「F0 の極端さそのものではない」という直感は**的中**。主犯は
   **WORLD d4c の D4CLoveTrain 二値判定が高音の有声フレームで誤爆し、
   非周期性を全帯域 1.0 (= bap 0 dB = 「このフレームは100%ノイズ」) に塗り潰す**こと。
   generator はこの誤った条件付けに忠実に従ってノイズを合成している。
3. この異常値は正規化後 z ≈ +1.1 の「ごく普通の値」なので、NaN 監視や
   z スコア監視では原理的に検出できない。数値破綻ではなく**意味的破綻**。
4. ルールベース補正 (本報告の Fix C+A+D) で特徴量レベルの異常は全指標が正常化する。
   実合成での検証結果は §10。
5. 高 F0 の学習分布外挿 (検体Aは有声フレームの55%が学習平均+3σ超) も独立した寄与因子として
   残存する。これは特徴量補正の射程外で、学習データ側でしか対処できない。

## 2. 調査方法

### 2.1 分析パイプラインの再現

`sifigan/bin/anasyn.py` と同一のパイプラインを独立に再実装して照合した:

```
x, sr = sf.read(path)                    # float64
x = librosa.resample(x, sr, 24000)       # 必要時のみ
f0, t = pw.harvest(x, 24000, f0_floor=100, f0_ceil=840, frame_period=5.0)
sp    = pw.cheaptrick(x, f0, t, 24000)
ap    = pw.d4c(x, f0, t, 24000)
mcep  = pysptk.sp2mc(sp, order=39, alpha=0.466)
bap   = pw.code_aperiodicity(ap, 24000)
cf0   = convert_continuos_f0(f0)         # anasyn.py:46 の複製
```

正規化は学習時統計 (`StandardScaler`、n_samples_seen=176,965,771) を使用。
generator への入力は mcep(40ch) + bap(3ch) = 43ch (f0/cf0 は scaler を通らず
生の Hz 値のまま SignalGenerator / dilated_factor に渡る — これは学習時と同一経路の仕様)。

### 2.2 診断体制

Claude Code のマルチエージェントワークフローで実施 (計6エージェント、全116ツールコール):
- 並列診断 5 観点: ①f0/cf0/dilated_factor ②sp→mcep ③ap→bap ④正規化後z ⑤検体横断
- 独立検証 1: 上記が報告した 13 件の異常候補をすべて別実装で再計算し、確認/反証。
  13 件中 13 件で数値は再現 (多くは小数点以下まで一致)、うち 3 件は因果の解釈を反証した。

### 2.3 ノイズ化区間の客観的定義

聴感ではなく数値でノイズ化を定義した:
- **対数メル距離**: 入力 (24kHzリサンプリング) と合成出力の 80-mel 対数スペクトル
  (n_fft=1024, hop=120) のフレーム毎 RMSE
- **自己相関周期性**: 100–840 Hz に対応するラグ範囲での正規化自己相関の最大値
  (win=1024)。クリーンな有声音で ≈0.83、無声音で ≈0.15

## 5. 結果③ (主機構): WORLD d4c の D4CLoveTrain 誤爆

### 5.1 現象

d4c は内部の D4CLoveTrain 判定 (二値) で「このフレームに調波構造があるか」を決め、
「無い」と判定したフレームは**全 513 bin の非周期性を 1−1e-12 に塗り潰す**。
bap は 3 帯域とも きっかり 0.0 dB となり、ボコーダには「このフレームは 100% ノイズ」
という条件付けが渡る。

検体A では**有声 (f0>0) 1300 フレーム中 216 フレーム (16.6%)** がこの状態。
うち大音量 (RMS > -30dB) の連続ランが 6–7 本・計 370–395ms:
t=0.455–0.475 / **0.760–0.885** / **1.015–1.045** / **4.525–4.610** / **4.705–4.740** /
5.125–5.170 / (7.290–7.310)。§4 の最悪 4 区間とほぼ一致する。

### 5.2 因果の立証

可聴有声フレーム n=1149 に対する統計 (独立検証エージェントによる):

- **r(d4c飽和, 歪み) = +0.575** (p=3.0e-102)。飽和フレームの平均歪み 1.106 vs 非飽和 0.607。
  単独最強の予測子で、cf0 の高さ (r=+0.382) を上回る。
- OLS `dist ~ cf0 + sat`: β_sat=+0.462 (cf0 換算 +365Hz 相当)、β_cf0=+0.00127/Hz。
  飽和を統制すると cf0 の相関は +0.316 に縮小。
- 飽和ペナルティは cf0 と強く交互作用: 350–400Hz で +0.056 → 400–450Hz で +0.581 →
  450–500Hz で **+0.922**。「高音で d4c が誤爆したとき」に最も壊れる。
- **決定的証拠**: d4c が「完全非周期」と判定したのに入力の自己相関周期性が 0.7 超
  (= 判定が客観的に誤り) のフレーム 58 個の平均歪みは **1.459**。周期性が同等で
  飽和していないフレームは 0.602 (**2.4 倍**)。最悪区間 t=0.760–0.885s の入力周期性は
  0.853 で、クリーン有声音の平均 0.828 と区別できないのに 100% 飽和している。
- **反例による裏付け**: t=1.700–1.800s は cf0 337.9–413.8 Hz と高いが飽和ゼロで、
  歪み 0.643・周期性 0.866→0.868 と無劣化。「高 cf0 だけでは壊れない」ことの直接の反例。

なお全飽和ランが誤爆ではない (t≈4.5s 台の一部は入力周期性 0.29–0.46 で判定自体は妥当)。
誤爆と正当な判定が混在している。

### 5.3 なぜ今まで検出できなかったか

bap = 0 dB を学習時統計で正規化すると **z = [+0.94, +1.07, +1.13]** にしかならず、
統計的には完全に分布内。generator は「訓練で頻繁に見た正常な値」を受け取り、
その**指示内容が間違っている**。NaN 監視・z スコア監視・値域チェックのいずれでも
原理的に検出できない。また ap ≤ 1 という構造上、bap の z は +1.13 が上限で、
bap の分布外れは負側 (過剰周期側) にしか発生し得ない。

### 5.4 付随する故障モード

1. **フレーム間ハードスイッチ**: 二値判定ゆえ発火/非発火の境界で bap が 5ms の間に
   最大 30.8 dB ジャンプ (15dB 超のジャンプが 24 箇所)。t=4.50–4.74s では通常値と
   0 dB を 20–25ms 間隔で何度も往復する。
2. **非発火時の過剰周期推定** (同じ d4c 高 F0 不安定性の裏面): 169 フレーム (10.8%、
   全て有声、f0 400–490Hz に集中) が bap z < −5 の「学習データのどのフレームよりも
   高域が周期的」な領域に落ちる。最小 z=−9.28 (t=6.585s, 9kHz帯, raw −25.8dB)。
   検体横断で bap max|z| は A系列のみ 8.8–9.8 と突出 (B 6.08 / F 6.02 / C 4.71 /
   E 3.30 / D 1.96)。|z|>5 の要素数は A 219 に対し B 3、他 0。

### 5.5 検体横断: 高 F0 で起きやすいが、話者/録音依存が大きい

有声フレームの d4c 飽和率 (拡張 10 検体、中央値F0 昇順):

| 検体 | 中央値F0 (Hz) | 飽和率 |
|---|---|---|
| E | 124.8 | 1.8% |
| D | 129.7 | 3.8% |
| A-3 (低ピッチ版) | 269.3 | 15.1% |
| F | 280.6 | 9.3% |
| C | 323.4 | 6.5% |
| B | 332.3 | 25.6% |
| A | 368.7 | 16.6% |
| A-2 | 369.1 | 15.6% |
| A-1 | 372.0 | 14.4% |
| A-4 | 399.0 | 27.8% |

Spearman ρ=+0.76 (p=0.011) の正相関はあるが単調ではない
(A-3 269Hz の 15.1% は C 323Hz の 6.5% の 2.3 倍、など)。A 系列 4 種は F0 が
269–372Hz とばらつくのに飽和率は 14–17% に固まっており、**F0 だけでなく話者・
録音特性に強く依存**する。「F0 がある範囲の外というだけで常に起きるわけではない」
という観察 (doc/260417-1-train.md §5) と整合する。

## 6. 結果④: 副次所見 (確認済み)

### 6.1 harvest のオクターブ下誤検出 — 可聴 (t=6.815–6.850s)

フレーム 1363–1370 で harvest が 228.9–275.6 Hz を出力するが、局所有声中央値は
424–433 Hz (比 0.53–0.65 ≒ 1/2)。信号レベルは −32〜−44 dBFS で明確に可聴。
dio+stonemask も pyin も同区間を無声判定しており harvest 単独の誤り。
励振信号とダイレーション係数が約 10 半音下にずれ、当該区間で出力は有声性を失う。
この区間は d4c 飽和とも重複しており (sat=100%)、**二重に壊れている**。
「低い声で F0 変更が効かない」症状の実体はこれ (harvest がオクターブ下の f0 を
出す → f0_factor を掛けても誤った基準からのスケーリングになる) と推測される。

### 6.2 デジタル完全無音直後の擬似有声 (t=2.810–2.860s)

入力にサンプル値が厳密に 0 の区間 (23,369 サンプル、t=2.60–2.79s) があり、直後の
フレーム 562–572 で harvest が 105.3–178.5 Hz (話者 p01=220.5Hz より下) を有声と
判定する。convert_continuos_f0 がこれを補間終端に使うため、直前 48 フレームの
無声区間で cf0 が 300.8 → 105.3 Hz へ **18.2 半音の下降グライド**を起こす。
当該区間の信号は −104 dBFS 級のため可聴影響はほぼ無いが、cf0 の最小値 (105.3Hz、
話者中央値の −21.7 半音) はここで発生している。

なお無音区間の出力は当方モデル −79.4 dBFS、作者モデル −90.3 dBFS (= 16bit の
±1 LSB) で、当方が約 11 dB 高いが実体は 3 LSB vs 1 LSB であり可聴閾を大きく下回る。

### 6.3 高 cf0 の学習分布外挿 — 補正では直らない独立寄与

学習時 cf0 統計は mean=164.03 Hz, sd=64.36 Hz (+3σ=357.1Hz, +4σ=421.5Hz)。
検体A は有声フレームの 55.0% が +3σ 超、31.3% が +4σ 超、最大 583.4Hz は +6.5σ。
d4c 飽和を統制した後も歪みとの相関 r=+0.316 が残る独立寄与因子。
LibriTTS-R (朗読音声) + VocalSet straight/vibrato では 430Hz 超の持続発声が
ほぼ学習できていないと考えられる。特徴量補正の射程外で、対処するなら
高 F0 データの追加かピッチシフト augmentation。

### 6.4 f0/cf0 の scaler バイパス (仕様の確認)

既定 aux_feats=["mcep","bap"] のため scaler['f0']/['cf0']/['uv'] はロードされる
だけで使われず、f0/cf0 は生の Hz 値のまま dilated_factor と SignalGenerator に渡る
(anasyn.py:144–181)。dilated_factor と SignalGenerator は物理周波数を要求する
関数なのでこれは正しい仕様であり、学習時と同一経路。ただし「高 F0 の分布ズレは
正規化で吸収されない」ことを意味する (6.3 の背景)。

## 8. ルールベース補正の設計と数値実験

特徴量レベルで 6 種の補正を実装・計測した (モデル推論なし)。

### 各補正の単独評価

- **Fix A — d4c 飽和フレームの ap 修復** (§5 対策、最重要):
  有声かつ全 bin 飽和のフレームを検出し、前後の非飽和有声フレームの ap から
  対数領域で線形補間して置換 → code_aperiodicity 再実行。
  有声 bap=0dB 216→**0**、最大ジャンプ 30.8→20.2dB、15dB超ジャンプ 24→4。
  副作用: 補間元が過剰周期側なので bap の |z|>5 要素が 219→285 に増える (Fix D で相殺)。
- **Fix A2 — bap 時間メディアンフィルタ** (簡易代替): k=5 でも飽和 216→207 と**不十分**。
  飽和が 5–26 フレームの連続ランを成すため窓内多数決が飽和側に倒れる。
- **Fix B — f0 5点メディアンフィルタ**: **失敗** (§7 参照)。
- **Fix C — 局所中央値比によるオクターブ下棄却** (§6.1/6.2 対策):
  前後 ±20 フレームの有声中央値より 6 半音以上低い有声フレームを無声化してから
  convert_continuos_f0 を再実行。棄却 19 フレーム・4 ラン
  (t=0.625–0.635 / 2.810–2.825 / 2.835–2.855 / 6.820–6.850)。§6.1 と §6.2 の両区間を
  正確に捕捉 (誤爆は 0.625–0.635s の 3 フレームのみ)。cf0 min 105.3→**159.6 Hz**、
  18.2 半音グライドが解消。
- **Fix D — bap の z クリップ** (|z|≤4): max|z| 9.28→**4.00**、|z|>5 要素 219→**0**。
  単独では飽和 (0dB 側) に無効。
- **Fix E — sp フロアクランプ**: **採用しない** (§7 参照)。

### 併用の効果 (検体A)

| 構成 | NaN/Inf | 有声bap=0dB | max\|z\|bap | \|z\|>5 | 最大ジャンプ | >15dB | cf0 min |
|---|---|---|---|---|---|---|---|
| ベースライン | 0 | 216 | 9.28 | 219 | 30.8dB | 24 | 105.3Hz |
| C のみ | 0 | 202 | 9.28 | 219 | 30.8dB | 24 | 159.6Hz |
| C+A | 0 | **0** | 9.28 | 285 | 20.2dB | 4 | 159.6Hz |
| **C+A+D** | 0 | **0** | **4.00** | **0** | **20.1dB** | **3** | **159.6Hz** |

C+A+D で全異常指標が同時に正常化。最悪区間の bap も
[−0.73, −0.86, −0.50] → [−20.68, −13.49, −12.73] dB と意味的に妥当な値になる。

### 限界

cf0 の分布位置 (有声中央値 +3.2σ) はどの補正でも変わらない。C+A+D は「d4c の誤爆で
不必要に壊れている分」(歪みへの最大寄与、r=+0.575) を取り除くものであり、
高 F0 外挿由来の残差 (r=+0.316) は残る。

## 9. anasyn.py への実装

`sifigan/bin/anasyn.py` に C+A+D をオプトインのフラグとして実装した
(既定はすべて false = 従来動作)。

```bash
uv run sifigan-anasyn ... \
    correct_f0_octave_drop=true \    # Fix C
    correct_ap_saturation=true \     # Fix A
    correct_bap_clip=true            # Fix D
```

| 設定キー | 既定値 | 内容 |
|---|---|---|
| `correct_f0_octave_drop` | false | Fix C: 局所中央値より閾値以上低い有声フレームを無声化 |
| `octave_drop_window` | 20 | 局所中央値の窓 (±フレーム) |
| `octave_drop_semitones` | 6.0 | 棄却閾値 (半音) |
| `correct_ap_saturation` | false | Fix A: 飽和有声フレームの ap を対数補間で修復 |
| `ap_saturation_threshold` | 0.999 | フレーム内の最小 ap がこれを超えたら飽和とみなす |
| `correct_bap_clip` | false | Fix D: bap を学習統計の ±z にクリップ |
| `bap_clip_z` | 4.0 | クリップ幅 (学習時標準偏差単位) |

適用順序: d4c 出力に Fix A → code_aperiodicity → Fix D → (uv/cf0 計算の直前に) Fix C。
sp/ap の WORLD 分析自体は元の f0 で行い、Fix C は f0/cf0/uv 特徴量のみに効く
(§8 の数値実験と同一条件)。

## 11. 結論と残課題

### 結論

1. 「極端な F0 でのノイズ化」の主因は、**F0 の値の異常でも NaN でもなく、
   WORLD d4c の D4CLoveTrain 二値判定が高音の有声フレームで誤爆し、
   generator に「このフレームは 100% ノイズ」という誤った条件付けを渡すこと**だった。
2. 誤爆フレームの ap を隣接フレームから補間するルールベース補正 (Fix A) を軸に、
   harvest のオクターブ誤検出棄却 (Fix C)、bap の学習統計クリップ (Fix D) を併用する
   ことで、**ノイズ化区間の歪みが対照区間と同水準まで解消し、他検体への回帰もない**
   ことを実合成で確認した。
3. 作者の事前学習モデルでも同一区間が壊れることの説明もつく: 原因が
   モデルではなく特徴量抽出 (WORLD d4c) 側にあるため。
4. 補正は `sifigan-anasyn` のオプトインフラグとして実装済み (既定 OFF、§9)。

### 残課題

1. **聴感確認**: 本報告の検証は客観指標のみ。`/mnt/y/tmp/audio_samples-anasyn-base` と
   `-fix10` (factor 1.0) / `-fixCAD` (全 factor) の試聴による最終確認が必要。
2. **高 cf0 の学習分布外挿** (§6.3): 補正後も残る理論上の寄与因子。ただし今回の
   計測ではノイズ化区間が対照区間と同水準まで回復しており、可聴レベルの支配要因は
   d4c 誤爆だった可能性が高い。さらに攻めるなら高 F0 データ追加または
   ピッチシフト augmentation で再学習。
3. **学習側パイプラインへの適用**: `extract_features.py` も同じ d4c を使うため、
   学習データにも飽和 bap が含まれている。学習データ側を Fix A 相当で清浄化して
   再学習すれば、さらに改善する可能性がある (今回は推論側のみ)。
4. **decode.py への適用**: 本補正は anasyn.py のみ。HDF5 経由の decode 経路にも
   同様の補正を入れるなら extract_features.py 側で行うのが筋。
5. **f0_factor ≠ 1.0 の評価**: 全 7 factor の補正版出力は生成済み (`-fixCAD`) だが、
   ピッチシフト時は入力との直接比較ができないため、客観評価は未実施。試聴で確認する。
