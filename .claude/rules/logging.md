## 学習・前処理のロギング

pakari上で学習や前処理（特徴量抽出、リサンプリング、統計量計算、データダウンロード等）を実行する際は、以下を必ずロギングすること。

### ログファイルの配置

- 永続ストレージ: `/repo/logs/{作業名}.log`
- B2 Storage: `s3://pakari/logs/{作業名}.log` にもアップロードする

### ログに含めるべき情報

1. **作業の開始・完了のタイムスタンプ**
2. **実行時のGitコミットハッシュとブランチ名**
3. **実行したコマンドとそのオプション**（パラメータが分かるように）
4. **コマンドの出力**（少なくとも要約。エラーは全文）
5. **入出力ファイルの数・サイズ**
6. **エラーが発生した場合の詳細と対処**

### 実行方法

- スクリプトを実行する場合: `tee -a /repo/logs/{作業名}.log` でパイプしてログを取る
- 対話的にコマンドを実行した場合: ツールコールの出力を元にログファイルを事後作成する（タイムスタンプ付き）
- 長時間タスクの場合はスクリプト内にログ出力を組み込む（`run_prepare.sh` の `log()` 関数を参照）

### Gitコミット

- 学習や前処理の実行前に、実行に使うコードの変更をコミットしておく
- コミットハッシュをログに記録し、再現性を確保する
